# CyberSecuritySuite AI Rules

1. Do not modify original repositories under source/.
2. Do not delete files from source/.
3. Do not merge open-source repositories blindly.
4. Preserve original copyright notices.
5. Preserve license files.
6. Check the license before reusing source code.
7. Keep third-party source isolated until integration is approved.
8. Do not replace working components without explaining the reason.
9. All new code should be placed in our own project directories.
10. Ask for approval before major architectural changes.
